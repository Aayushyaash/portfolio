A modern, responsive portfolio website built to showcase projects and skills.

-   **Architecture**: Custom Node.js static site generator that compiles Markdown content into a structured JSON data layer.
-   **Frontend**: Vanilla JavaScript for client-side rendering (CSR) using the generated data, ensuring fast transitions and dynamic updates.
-   **Styling**: styled with Tailwind CSS for a highly responsive and dark-themed design with smooth animations.
-   **Features**: Dynamic project filtering, interactive timeline, mobile-responsive navigation, and automated build process.
